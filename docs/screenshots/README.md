## 截图要求

- 格式 PNG，宽度建议 1600–2400px（2x 屏直接截即可，GitHub 会自动缩放）
- **脱敏（必须）**：真实目标域名/IP、Cookie、Authorization、验证码、身份证/手机号等一律打码
- 不要包含本机绝对路径、会话 ID、内部 errno 等无关信息
- 只截授权范围内的演示环境

> `01-explore.png` 里的目标 IP 已用灰条打码；后续补图请同样处理。
